
#  Task-7: Online Course Sales Analysis with Python and SQLite

This project shows how to use Python with SQLite to analyze online course sales. It demonstrates basic SQL usage, loading query results into pandas, and creating a revenue chart with matplotlib.

##  Objective

- Create a SQLite database and table for course sales
- Insert mock sales data for different courses
- Use SQL to summarize total enrollments and revenue per course
- Load results into pandas
- Display and visualize the data

##  Tools Used

- Python 3
- SQLite (`sqlite3`)
- pandas
- matplotlib
- Jupyter Notebook or a .py file

## Files Included

- `Task-7.py` — Python script for the analysis
- `barchart.png and table.png` — saved revenue bar chart
- `README.md` — this documentation

##  How to Run

1. **Install packages**:
   ```bash
   pip install pandas matplotlib
   ```

2. **Run the script**:
   ```bash
   python course_sales_analysis.py
   ```

3. **Output**:
   - Console: Table showing enrollments and revenue by course
   - Plot: Bar chart visualizing revenue
